# Shop app

**The app is in [`web/`](web/README.md)**: a Next.js PWA for small shops (cash
sales, stock with barcodes and stickers, cash drawer, reports, employees with
approvals, notebook). It installs on Android and works on a PC, works offline,
and keeps its data in a Google Sheet. Start there.

Developer map: [`CLAUDE.md`](CLAUDE.md).
